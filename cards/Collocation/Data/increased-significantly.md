# Front

<div class="hint">TASK1_DATA &middot; verb + adverb &middot; <span class="no">significantly grew</span></div>

Type the missing verb:

<span class="ex">"The number of students ____________ during the period under review."</span>

---

# Type

increased significantly, rose significantly, grew significantly, increased sharply, rose sharply, grew

---

# Back

The number of students **<span class="ans">increased significantly</span>** during the period under review.

---

<div class="pat">the number <b>increased</b> + adverb &nbsp;&middot;&nbsp; the population <b>rose</b> + adverb</div>

* the number of X **increased / rose / grew**
* the figure **stood at / climbed to** 50%
* sales **surged / plummeted / fell**

*Tip: put the adverb after **increased / rose**: "rose significantly". "Significantly grew" is grammatical but stilted in Task 1, and **grow** is better for things that get bigger, not for numbers or percentages.*
