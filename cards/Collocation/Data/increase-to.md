# Back

The figure increased **<span class="ans">to</span>** 50% by 2020.

---

<div class="pat">increased <b>to</b> 50% &nbsp;&middot;&nbsp; increased <b>by</b> 20 percentage points</div>

**to** = the value it ended at. **by** = the size of the change. See the next card for **by**.

*Tip: "increase to 50%" describes the final figure; "increase by 50%" describes a 50% relative rise from the starting value. In Task 1 always be explicit which one you mean.*
