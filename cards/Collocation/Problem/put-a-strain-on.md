# Front

<div class="hint">TASK2_PROBLEM &middot; a burden that is hard to sustain</div>

Type the missing noun:

<span class="ex">"The growing elderly population put a ____________ on the health service."</span>

---

# Type

strain, pressure, burden, drain, toll

---

# Back

The growing elderly population put a **<span class="ans">strain</span>** on the health service.

---

<div class="pat">put a <b>strain</b> on + person / system / service</div>

<span class="ex">Rapid urban growth has put a strain on infrastructure.</span>

*Tip: **strain on** is a bit stronger than **pressure on** &mdash; it suggests the system is being pushed beyond what it can carry, so it is the better word in a Task 2 solution paragraph. **Put a strain on**, never <span class="no">put strains on</span> here.*
