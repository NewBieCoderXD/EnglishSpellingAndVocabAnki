# Front

<div class="hint">TASK1_DATA &middot; fix the sentence &middot; a number cannot "experience"</div>

Type the missing verb:

<span class="ex">"The number of households owning a car <span class="no">experienced</span> ____________ sharply."</span>

---

# Type

increased, rose, grew, climbed, went up

---

# Back

The number of households owning a car **<span class="ans">increased</span>** sharply.

---

<div class="pat">the number of X <b>increased</b> / <b>rose</b> / <b>grew</b></div>

<span class="ex">The number of car owners rose steadily between 2000 and 2020.</span>

*Tip: numbers take **increase / rise / grow / climb / fall / decline / decrease**, not **experience / suffer / witness** unless something happens *to* them. **The figure stood at 40%** is another safe formulation.*
