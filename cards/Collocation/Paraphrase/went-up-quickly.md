# Front

<div class="hint">PARAPHRASE &middot; "went up quickly" &rarr; one precise verb</div>

Type the missing verb:

<span class="ex">"The number of users went up quickly. &nbsp;&rarr; &nbsp;The number of users ____________."</span>

---

# Type

surged, rose sharply, increased rapidly, climbed steeply, soared

---

# Back

The number of users **<span class="ans">surged**.

---

<div class="pat">X <b>surged / soared</b> &nbsp;&middot;&nbsp; X <b>rose / climbed sharply</b> &nbsp;&middot;&nbsp; X <b>increased / grew rapidly</b></div>

* **surge / soar** &mdash; a sudden, sharp jump: "Prices surged in 2020."
* **rise / climb** &mdash; go up (steady or not): "The figure rose to 50%."
* **increase / grow** &mdash; go up by some amount: "It increased by 10%."

*Tip: **soar** is for a very large, steep rise; **surge** for a sudden one. "The figure went up" belongs to speech, not to Task 1.*
