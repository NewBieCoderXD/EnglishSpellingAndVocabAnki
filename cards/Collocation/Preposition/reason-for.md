# Front

<div class="hint">PREPOSITION &middot; <span class="no">reason <b>of</b></span></div>

Type the preposition:

<span class="ex">"The reason ____________ the decline in literacy was a lack of funding."</span>

---

# Type

for, of, behind

---

# Back

The reason **<span class="ans">for** the decline in literacy was a lack of funding.

---

<div class="pat">the reason <b>for</b> + problem &nbsp;&middot;&nbsp; the cause <b>of</b> + problem &nbsp;&middot;&nbsp; the cause <b>in</b> + place</div>

* the reason **for** deforestation / the reason **why** people deforest
* the main cause **of** deforestation
* the main cause **in** South America

*Tip: <span class="no">the reason of</span>. In Task 1 charts prefer <span class="ok">cause of</span>, which is the academic collocation; in Task 2 <span class="ok">the reason for</span> is perfectly natural.*
