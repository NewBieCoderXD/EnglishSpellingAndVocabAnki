# Front

<div class="hint">TASK1_CAUSE &middot; preposition &middot; the place, not the problem</div>

Type the preposition:

<span class="ex">"Cattle ranching was the main cause ____________ South America."</span>

---

# Type

in

---

# Back

Cattle ranching was the main cause **<span class="ans">in</span>** South America.

---

<div class="pat">the main cause <b>in</b> + region / period &nbsp;&middot;&nbsp; the main cause <b>of</b> + problem</div>

<span class="ex">The main cause in Central Africa was small-scale farming.</span>

*Tip: <span class="no">the main cause for South America</span> &mdash; <b>for</b> goes with <i>the reason for</i>, not with a region.*
