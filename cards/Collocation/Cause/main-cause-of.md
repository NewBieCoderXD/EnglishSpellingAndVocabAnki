# Back

Cattle ranching was the main cause **<span class="ans">of</span>** forest loss.

<div class="pat">the main cause <b>of</b> + problem</div>

**cause of** <span class="pos">noun phrase</span>

<span class="ex">The main cause of deforestation in South America was cattle ranching.</span>

*Tip: <b>cause of</b> a problem, but <b>cause in</b> a place &mdash; see the next card.*
