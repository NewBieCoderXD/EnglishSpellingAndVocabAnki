# Back

<div class="w">about vs above</div>

<p>1. <b>about</b> /əˈbaʊt/ — schwa + /aʊ/ · 2. <b>above</b> /əˈbʌv/ — schwa + /ʌ/.</p>

<p>Both start identical (schwa), then split: "bout" has /aʊ/ (as in "out"), "bove" has /ʌ/ (as in "ove"→"uv").</p>

<span class="ex">a-BOUT /əˈbaʊt/ talks about out; a-BOVE /əˈbʌv/ points up.</span>
